## DHIS2 Stroke Data Analysis – Uganda

### Overview
This repository contains the R scripts used for the analysis of national DHIS2 stroke data from Uganda. The script supports the analyses presented in the manuscript: "**_RISING STROKE TIDE IN UGANDA: A DECADE OF TRENDS AND FORECASTS FROM NATIONAL DHIS2 DATA, 2016–2028_**"

### Data
The analysis used routine health information system data obtained from the Uganda DHIS2 platform. The underlying DHIS2 data are not included in this repository because they are subject to data access and confidentiality restrictions.

### Analysis
The R scripts include procedures for:
- Data preparation
- Descriptive analysis
- Temporal trend analysis
- Forecasting
- Generation of tables and figures

### Repository structure
R/DHIS2_stroke_analysis.R

### Software
The analysis was conducted using R.

### Reproducibility
The scripts are provided to support transparency and reproducibility of the analytical workflow. Because the underlying DHIS2 data are not publicly available, the complete analysis cannot be independently reproduced without authorized access to the data.

### Code availability
The analysis scripts are publicly available in this repository.
